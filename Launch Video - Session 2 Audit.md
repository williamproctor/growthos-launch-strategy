## ⚠ Flags — the lines to fix or pick up

### 1. The product name "GrowthOS" is never spoken on tape
Marcel says *"a system of growth for your website"* and the URL *"growthx.ai"* — but he never says **"GrowthOS"** out loud. Since we just locked the name, decide:
- **(a)** one 5-second pickup: *"That's what we built. GrowthOS."* (matches the V2 script reveal), or
- **(b)** carry the name on a lower-third / endcard only (the B-roll plan already calls for this) and let "system of growth" be the spoken phrase.

→ Recommend **(a)** — a single clean name-drop is cheap and makes the reveal land.

### 2. "System of record" vs "system of context" — naming collision
- Locked framework + Session 1 demo: **Record** · Intelligence · Action · Learning ([27:08], [36:38] of the demo say "system of record").
- Session 2 here: **Context** · Intelligence · Action · Learning ([16:42] "system of context").

Intelligence / Action / Learning match across both. Only the **first system** conflicts. Pick one name and get a matching take:
- If the framework stays **Record**, grab one pickup: *"Think of it as a system of record…"*
- If we switch the framework to **Context**, Session 2 already has it clean — and arguably "context" is the more self-explanatory word for a cold audience.

→ **Needs a decision from Harmony**, then a possible 1-line pickup. This is the only true framework inconsistency.

### 3. Harmony's locked POV close is not verbatim
The locked close is *"Stop over-engineering. Stop buying tools that hand marketers more work. Start marketing again."* Closest on tape:
> [00:08:09] "I think the answer is become a great marketer." · [00:08:25] "Another tool is not the answer."

These cover the spirit but aren't the exact triad. → If we want the literal line as the closer, it's a 6-second pickup. Otherwise "become a great marketer" closes it well.

### 4. The proven scene-opener (from V2) isn't here
V2's strongest asset was the cold-open scene — *"I had a call yesterday with a CMO… she just laughed."* Session 2 openers are declarative ("Being a marketer is one of the hardest jobs," "Marketing is broken"), which are good but less sticky. → If we want the scene hook, it's still a pickup (V2 already flagged it as adapt-to-your-truth). Otherwise the declarative open is fully covered.

### 5. Pick the clean takes (profanity)
Two strong lines have profanity: [00:01:16] "fucking hard" and [00:07:24] "shitty engineers." Clean alternates exist ([00:01:48] "Marketing is broken," [00:07:32] "become engineers"). → Use clean takes for the broad launch cut; the edgier takes can live in an organic/social variant if desired.
